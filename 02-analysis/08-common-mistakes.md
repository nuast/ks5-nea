# Common Analysis Mistakes (and Fixes)

## 1) Vague problem statement

**Mistake:** “I want to make a useful app.”  
**Fix:** state users, current issue, impact, and boundary.

## 2) Generic computational justification

**Mistake:** “Computers are faster.”  
**Fix:** explain the exact rule-based/data-processing benefits.

## 3) Weak stakeholder choice

**Mistake:** choosing people with no real connection to the problem.  
**Fix:** use real users/decision-makers and explain their role.

## 4) Research dump

**Mistake:** pasting raw transcripts/screenshots with no commentary.  
**Fix:** summarise key findings and decisions.

## 5) Requirements not linked to evidence

**Mistake:** features appear with no source.  
**Fix:** add stakeholder + evidence source + justification for each requirement.

## 6) Vague success criteria

**Mistake:** “easy to use”, “works well”.  
**Fix:** define measurable thresholds and test methods.

## 7) Scope too large

**Mistake:** trying to build a whole organisation-wide platform.  
**Fix:** narrow to one process, one context, and realistic deliverables.
