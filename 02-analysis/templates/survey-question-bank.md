# Survey Question Bank

Use a mix of multiple-choice, rating, and short free-text questions.

## Sample questions

1. How often do you perform this task?  
   - Daily / Weekly / Monthly / Rarely
2. Which issue affects you most?  
   - Slow process / Lost records / Errors / Hard to find data / Other
3. Rate the importance of these features (1 = not important, 5 = very important):  
   - Quick data entry  
   - Search/filter  
   - Error prevention  
   - Export/reporting
4. Which devices do you use most for this task?  
   - Desktop / Laptop / Tablet / Phone
5. What is one improvement that would save you the most time?

## Tips

- Keep surveys short (usually 6–12 questions).
- Avoid leading questions.
- Include one open question for unexpected insights.
