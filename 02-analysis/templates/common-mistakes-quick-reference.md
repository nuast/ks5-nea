# Common Mistakes Quick Reference

## Red flags to remove before submission

- Vague aim instead of clear problem definition
- No project boundary
- Generic computational justification
- Weak or irrelevant stakeholders
- Research notes with no analysis commentary
- Requirements with no evidence link
- Unnumbered requirements
- Vague success criteria
- Over-ambitious scope
- Repeated content across multiple files

## Quick fix rule

For each major point, include:

**Evidence -> Decision -> Requirement ID -> Success Criterion ID**
