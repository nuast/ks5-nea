# Interview Question Bank

Pick questions that fit your project. Do not ask all of them blindly.

## Current process and problems

- Can you describe your current process step by step?
- Which part causes the most mistakes or delays?
- What workarounds do you currently use?

## Feature priorities

- Which tasks must be quickest in the new system?
- What information must always be visible?
- Which features are essential vs optional?

## Usability and constraints

- What would make this system easier to use in real conditions?
- Are there any accessibility needs to consider?
- What devices and operating systems are actually used?

## Validation questions

- What should happen when invalid data is entered?
- Which errors are most important to prevent?

## Closing

- If only three features could be built first, which three?
- Is there anything else that would make this genuinely useful?
