# Success Criteria Checklist

A criterion is ready only if all are true:

- [ ] It is linked to one or more requirement IDs.
- [ ] It defines exactly what success looks like.
- [ ] It is measurable (time/count/percentage/pass condition).
- [ ] It states how it will be tested.
- [ ] It is realistic for your scope and dataset.
- [ ] It avoids vague language (“good”, “nice”, “easy”).
