# Stakeholders

Identify stakeholders early and explain how each one contributes to analysis, testing, and evaluation evidence.

- Who are primary and secondary stakeholders?
- How does each stakeholder currently interact with the problem?
- How available are they for feedback/testing?
- What risks exist if access is limited?
