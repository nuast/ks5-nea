# Authenticity and AI Use

This NEA must be your own work. Use support tools to learn and research techniques, then create and explain your own solution.

- Do **not** submit AI-generated report text or code as if it is your own original work.
- If you used AI, websites, books, videos, forums, libraries, or code snippets, reference them.
- Adapt ideas to your own project and explain your decisions.
- Keep a brief record of what help was used and how it informed your work.
